## 📝 Sobre o Projeto
Avaliação Checkpoint 4 para a disciplina de Web Development. O projeto inclui:
- Navegação através de rotas (Home, Sobre, Planos, Calculadora IMC, Contato)
- Calculadora funcional de IMC
- Formulários e cards interativos
- Versionamento feito utilizando a branch `dev` e merge para a principal
